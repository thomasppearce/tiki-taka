# Expected threat (xT)

Expected threat values a position on the pitch by how likely possession there leads to a goal in the next few actions. Moving the ball from a low-threat zone to a high-threat one adds threat; losing it gives the threat away.

## How Match Desk uses it

Every pass and carry is scored by the threat it adds. A pass that takes the ball from midfield into the space behind a defence adds a lot; a safe pass sideways adds almost nothing. That is how the desk decides which plays were decisive, and it powers the momentum line: each team's share of threat created over the last few minutes.

## Reading it on air

- A decisive pass is one that adds a large amount of threat in a single action.
- Momentum built on threat, not possession, shows which side is genuinely creating danger.
